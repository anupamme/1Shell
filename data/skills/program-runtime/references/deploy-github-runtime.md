# 一键部署 GitHub 项目运行时

运行目标：把 `inputs.github_url` 部署到当前目标 VPS 的 `inputs.port`。

## 阶段

1. `env_check`
   - 点亮：正在读取 VPS 环境。
   - 探测系统、架构、包管理器、网络、端口占用、常用运行环境。
   - 完成：VPS 环境读取完成。

2. `repo_analysis`
   - 点亮：正在读取 GitHub 仓库。
   - 获取仓库，读取文件结构，判断技术栈和启动方式。
   - 完成：仓库分析完成。

3. `deploy`
   - 点亮：正在安装依赖并部署。
   - 安装依赖、构建项目、启动服务或配置进程管理。
   - 完成：项目部署命令执行完成。

4. `verify`
   - 点亮：正在验证访问。
   - 验证进程、端口监听、本机 HTTP、必要时外部访问条件。
   - 完成：访问验证完成。

5. `result`
   - 点亮：正在生成结果。
   - 调用 `publish_result` 输出结果。

## 成功结果必须包含

- 访问地址。
- 目标 VPS。
- GitHub 项目链接。
- 端口。
- 启动方式或服务名。
- 验证证据。

## 失败结果必须包含

- 失败阶段。
- 已完成内容。
- 失败原因。
- 用户下一步应该怎么做。
