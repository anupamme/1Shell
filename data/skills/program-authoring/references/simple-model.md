# Program 简单模型

Program = 提示词模板 + 必要输入字段 + 自动执行 + 默认结果回报。

例子：

用户需求：把一个 GitHub 项目部署到某台 VPS 的某个端口。

提示词模板：

“帮我把 {github_url} 部署到用户选择的 VPS 的 {port} 端口。”

前端输入：
- VPS：Program 页面目标主机选择。
- GitHub 项目：`github_url`。
- 端口：`port`。

运行：
- AI 自己读取 VPS 环境。
- AI 自己读取仓库。
- AI 自己判断技术栈和部署方式。
- AI 自动部署并验证。

结果：
- 成功还是失败。
- 怎么访问。
- 访问地址。
- 如果失败，失败在哪里。
